== Runtime dependencies

`jakarta.servlet.jsp:jakarta.servlet.jsp-api:4.0.0`, with `jakarta.servlet-api:6.1.0` and `jakarta.el-api:6.0.1` — nothing else. At run time an Expression Language implementation (Peano) and a servlet container (Foy) complete the picture.

Build-time tooling may take a dependency when it saves rewriting something done elsewhere; each one will be named on this page. None so far.
