== Runtime dependencies

`jakarta.servlet.jsp:jakarta.servlet.jsp-api:4.0.0`, with `jakarta.servlet-api:6.1.0` and `jakarta.el-api:6.0.1` — nothing else. At run time an Expression Language implementation (Peano) and a servlet container (Foy) complete the picture.

Build-time tooling may take a dependency when it saves rewriting something done elsewhere; each one will be named on this page. None so far.

`ibarra-compiler` has no production library dependencies. Its parser requires the
JDK `java.xml` module; generation/compilation also needs the optional
`java.compiler` module resolved in a full Java 25 JDK. JUnit, Peano and Ibarra
core are test-scoped in the compiler; Peano is test-scoped in the core.
The SPI and Peano compiler dependencies are deferred until their APIs exist.

`GenerationOptions.DEFAULT` disables startup EL. `withStartupEl(true)` explicitly
enables the initial preview interpreter path; build-time EL compilation remains
unfinished. `PageGenerator`, `GeneratedPage`, `PageCompiler`, `JspPropertyGroup`
and `GenerationOptions` are in `io.vidocq.ibarra.compiler`.
