== Passing coverage and CI

Passing classes include JspFactory, JspEngineInfo, JspWriter, PageContext,
ErrorData, BodyContent, DynamicAttributes, TagAdapter, VariableInfo, several
EL/implicit-resolver API tests, implicit objects, character-sequence/EL/encoding
configuration, i18n and scripting syntax.
Other classes pass partially; remaining failures include translation,
tag metadata/files, routing, API and signature-tooling gaps.

Ordinary TLD keyword/setter fixes add 40 confirmed passes, remove three setup
blockers and restore four previously failing EL methods, without a regression
among previously passing methods. See xref:modules/tag-handlers.adoc[Tag handlers]
for the actual-property binding rules and remaining boundaries.

The three JspIdConsumer methods now pass with stable compiler-provided tag IDs,
including inherited classic/simple consumers. No previous pass regressed.
See xref:modules/tag-handlers.adoc[Tag handlers] for identifier initialization,
repeatable fragments and protection of the reserved container setter.

Direct legacy WAR property accessors restore sixteen more methods across
BodyTagSupport, TagSupport, TryCatchFinally and scripting EL coercion. The
TryCatchFinally failure was its private verifier's denied property access;
handler lifecycle generation is unchanged. No previous pass regressed.
See xref:modules/official-tck-runner.adoc[the runner reference] for the bounded
property services and preserved reflection/module boundaries.

Direct collection method tables restore the official methodInfoTest and
positiveELDeferredMethodValueTest. Compiled Vector calls now expose metadata and
invoke without reflection, preserving native list property resolution. No previous
pass regressed; this bounded runner adaptation does not alter production packaging.

All seven standard forward-action methods now pass. The runtime refuses forwarding
after unbuffered output or a JSP flush even while the Servlet response remains
uncommitted; it includes error pages after emitted output. The original exception
is retained, unwritten pages still forward, and no previous pass regressed.
See xref:internals.adoc[Runtime internals] for the output-state rules.

The parallel compiler batch restores three methods through direct literal BeanInfo
editor conversion, opaque tagdependent bodies and precompilation request validation.
The resulting run has 44 completely passing classes and no regression against main.
Valid precompile requests now suppress the page body, including through jsp-file
aliases; invalid decoded values send HTTP 500. The stronger HTTP counter test
checks suppression beyond the official positive tests' text assertion.

The unsafe include-forward prototype was withheld after a reproduced child
response-wrapper regression. Its typed replacement now restores the original
positiveIncludeForwardTest (IBARRA-119/130), preserving all 518 prior passes.
All twelve include-action methods pass and the full run has 48 completely passing
classes. The stronger HTTP fixture checks wrapper headers, cached writers, nested
ancestors, stopped parent side effects and missing-target 404 behavior.
The source evidence and follow-up are in
link:{repo-ibarra}/src/branch/main/studies/include-forward-wrapper-dispatch.md[the dispatch study].

The signature/envelope follow-up restores eight more methods with no regression.
The unchanged official signature driver checks the configured spec API jars;
tagdependent named attributes use ordinary semantics while explicit bodies stay
opaque. XML output accepts its specified yes/no omission aliases and rejects
nonempty bodies before normalization. All JSP document general methods now pass;
that stage's final run had 47 completely passing classes. The subsequent XML output
delivery collects declaration and DOCTYPE settings statically over the translation
unit and emits declaration, DOCTYPE and body in order. Source DTDs and external
entities remain rejected; no official fixture was changed.

`official-pages-tck-smoke` runs on pull requests and `main`. It clean-installs
Ibarra, runs 34 adapter regression tests, then three official JspFactory
tests, one JspEngineInfo test and fourteen character-sequence/EL/encoding
configuration tests. This deliberately bounded regression check
does not claim 100% Pages coverage. Full-suite certification is milestone I8;
100% PASS becomes the gate once that suite is green.

== Runner

`ibarra-tck` enters the reactor only under `-Ptck`; official artifact scanning
requires `-Ptck,tck-official`. Coordinates verified from the embedded POM:
`jakarta.tck:jakarta-pages-tck:4.0.0`, distributed by Eclipse rather than Central.
Preparation preserves the original POM and supplies the omitted JavaTest 5.0
dependency, with mandatory SHA-256 checks.

The adapter precompiles pages before launching modular Foy/Chappe; the server
contains neither compiler nor `java.compiler` and retains reflection denial.
It supports multiple isolated WARs and their filesystem resources. Root JSP
property groups reach the compiler through build-side descriptor parsing.
Explicit deployment precompilation retains genuine per-page translation failures
as compiled error servlets, so valid pages and negative translation tests can
coexist. No source is parsed in the server. Normal packaging still rejects errors.
Root web.xml Servlet/filter/listener classes in WEB-INF/classes now receive direct
build-generated Foy factories, with application packages kept private. This removes
three setup blockers and adds three passing API tests; general configuration now
executes and exposes three method errors. No previous pass regressed.
Legacy WAR libraries now assemble into the existing private module, preserving
shared packages, physical JAR references and distinct TLD discovery paths.
This removes the final two setup blockers and adds 15 passes from 22 newly runnable
methods. Seven new method errors remain, with no regression among previous passes.
Unadapted library metadata, Servlet annotations and initializers fail explicitly;
invalid global metadata still aborts deployment.

See xref:modules/official-tck-runner.adoc[Official TCK runner] for dependencies,
commands, artifact preparation, retained logs and limits.
