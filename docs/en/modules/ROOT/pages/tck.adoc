== Runner

`ibarra-tck` enters the reactor only under `-Ptck`; official artifact scanning
requires `-Ptck,tck-official`. The official distribution is
`jakarta.tck:jakarta-pages-tck:4.0.0`, published by Eclipse rather than Maven
Central. Preparation preserves its embedded POM, supplies the omitted JavaTest
5.0 dependency and checks artifact SHA-256 digests.

The adapter precompiles pages before launching modular Foy/Chappe. The server
contains neither the compiler nor `java.compiler`, and retains reflection denial.
It supports isolated WARs and filesystem resources. Root JSP property groups reach
the compiler through build-side descriptor parsing. Explicit deployment
precompilation preserves per-page translation failures as error servlets so valid
pages and negative translation tests can coexist; normal packaging still rejects
translation errors.

See xref:modules/official-tck-runner.adoc[Official TCK runner] for dependencies,
commands, artifact preparation, retained logs and limits.
