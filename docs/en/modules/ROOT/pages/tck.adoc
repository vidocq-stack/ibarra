= TCK status
:description: Initial official Jakarta Pages 4.0 results; full certification remains pending.

[.lead]
The official Jakarta Pages 4.0.0 TCK now runs through a build-side Arquillian
adapter on Foy. The eighteen-test smoke subset passes. The full diagnostic attempt
is incomplete and failing; Ibarra is not certified.

== Recorded baseline

Run date: 2026-10-12, Temurin Java 25 and Maven 3.9.16.

[source,bash]
----
./run-official-tck-pages-4.0.sh all --no-install --no-prepare
----

The current reactor had already been installed and official artifacts prepared.
The verified official binary contains 92 test classes and 682 declared JUnit
`@Test` methods. The run records *427 passing methods* and *179 failing methods*,
plus *8 class-level setup/deployment errors*. Surefire therefore reports 614
entries, 187 errors, zero assertion failures and zero skips, and exits nonzero.
The upstream HTTP assertion helper reports failures as exceptions.

*427/682 = 62.6% confirmed passes*, a conservative floor, not a complete suite
pass rate. Only 606 method entries ran. Class-level errors prevent whole groups
of methods from executing; they must not be counted as executed methods.

The detailed command, binary inventory, counts and remaining categories are in
link:{repo-ibarra}/src/branch/main/ibarra-tck/BASELINE.md[the recorded baseline].
Peano's independent EL TCK result is not a Pages TCK result.

== Passing coverage and CI

Passing classes include JspFactory, JspEngineInfo, JspWriter, PageContext,
ErrorData, BodyContent, DynamicAttributes, TagAdapter, VariableInfo, several
EL/implicit-resolver API tests, implicit objects, character-sequence/EL/encoding
configuration, i18n and scripting syntax.
Other classes pass partially; the full suite remains blocked by translation,
tag metadata/files and WAR-adaptation gaps.

`official-pages-tck-smoke` runs on pull requests and `main`. It clean-installs
Ibarra, runs seven adapter regression tests, then three official JspFactory
tests, one JspEngineInfo test and fourteen character-sequence/EL/encoding
configuration tests. This deliberately bounded regression check
does not claim 100% Pages coverage. Full-suite certification is milestone I8;
100% PASS becomes the gate once that suite is green.

== Runner

`ibarra-tck` enters the reactor only under `-Ptck`; official artifact scanning
requires `-Ptck,tck-official`. Coordinates verified from the embedded POM:
`jakarta.tck:jakarta-pages-tck:4.0.0`, distributed by Eclipse rather than Central.
Preparation preserves the original POM and supplies the omitted JavaTest 5.0
dependency, with mandatory SHA-256 checks.

The adapter precompiles pages before launching modular Foy/Chappe; the server
contains neither compiler nor `java.compiler` and retains reflection denial.
It supports multiple isolated WARs and their filesystem resources. Root JSP
property groups reach the compiler through build-side descriptor parsing.
Explicit deployment precompilation retains genuine per-page translation failures
as compiled error servlets, so valid pages and negative translation tests can
coexist. No source is parsed in the server. Normal packaging still rejects errors.
Libraries and Servlet component factories/annotations/initializers that cannot
yet be adapted fail explicitly; invalid global metadata still aborts deployment.

See xref:modules/official-tck-runner.adoc[Official TCK runner] for dependencies,
commands, artifact preparation, retained logs and limits.
